Aurora

A deterministic operating-system kernel simulator you can step through in the browser. Spawn processes, choose a scheduler, and watch scheduling, virtual memory and syscalls unfold tick by tick.

This is a teaching-accurate model of kernel mechanics, not a bootable operating system. It reimplements the same model as the Rust engine. Source and the full engine at github.com/pavanchow/aurora.

How to use this playground

  1. Pick a scheduler. Use Scheduler policy. Round robin gives every process an equal slice of size RR quantum. Priority runs the most urgent first and ages waiters so none starve. MLFQ starts new work at the top queue and demotes CPU-bound work, boosting everyone periodically so nothing starves.
  2. Size memory. Set Physical frames small (try 3 or 4) so processes compete for frames, and choose a Page replacement policy to see who gets evicted.
  3. Add processes. Fill name, priority (lower is more urgent), CPU burst, pages touched and arrival tick, then press Add process. Each process interleaves compute with page accesses, so it exercises both the scheduler and the memory system.
  4. Step or run. Press Step to advance exactly one tick and study every change, or press Run to play until all processes terminate. Press it again to pause.
  5. Read the timeline. Each row is a process, each column a tick. A green cell means that process held the CPU that tick. The idle row shows ticks where the CPU had no runnable work.
  6. Watch memory. The frame grid shows which page of which process occupies each physical frame. A red frame just faulted in, a purple flash marks the frame whose page was evicted. The page table column shows each process mapping virtual pages to frames.
  7. Follow the syscalls. The syscall log lists every sleep, yield, memory map, IPC and file call, and whether the caller continued or blocked.
  8. Reset. Press Reset to clear everything and start again with new settings.
